# TOYP Motion V2 — sin voz en off

Revisión solicitada a partir de la referencia https://www.tiktok.com/@ssupernova.studio/video/7693660982446492948 . Se revisó la referencia y se adaptó su lenguaje de producto/interfaz: entrada en perspectiva, acercamientos, cifras, filas de datos, cursor y remates tipográficos. Los gráficos y audio del TikTok no se reutilizan.

36 s, 1080×1920, 60 fps. Instrumental original sintetizado a 120 BPM y SFX; sin locución. Se conservan los cuatro niveles, importes, beneficios, modalidad de intercambio y contactos. La interfaz es motion design conceptual, no una aplicación funcional de patrocinio.

- **TOYP_Motion_V2.mp4**: montaje completo.
- **TOYP_V2_Preview.mp4**: primeros nueve segundos.
- **TOYP_Proyecto_V2.zip**: código, assets, fuentes, audio V1/V2, documentación e informe. npm ci y npm run render exportan V2; npm run render:v1 conserva V1.
- **TOYP_V2_Encuadres.jpg**: once encuadres revisados.
- **verification.json** y **SHA256.json**: comprobaciones y hashes.

Render, TypeScript y build verificados. 2160 frames, decodificación completa, correlación de audio .9999966, pico verdadero -0.9 dBFS, sin fotogramas negros inesperados. La duración de video es 36 s; el contenedor AAC indica 36.011 s.

La versión anterior permanece en la carpeta superior. Main no se modifica.
