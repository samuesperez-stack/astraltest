# CHEKI V3 — recorrido continuo / prueba de cámara

[Descargar prueba animada de seis segundos](https://github.com/samuesperez-stack/astraltest/raw/refs/heads/cheki-freezer-deliverables/deliverables/cheki-freezer/v3/CHEKI_V3_Camera_Test.mp4)

Nuevo escenario 3D: cámara continua entre puertas, estantes, letras espaciales, objetos suspendidos, monitores de memes y arco de salida. Personajes y algunos objetos fotográficos se integran como capas 2.5D. No es una grabación real ni una actuación con lip-sync.

Esta prueba comprueba la trayectoria inicial; el render completo está en curso y contiene ajustes posteriores de separación de palabras y cristales. V1 y V2 se conservan en las carpetas anteriores.
