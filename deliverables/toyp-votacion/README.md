# Panel de jurados TOYP

[Descargar proyecto](TOYP_Panel_Proyecto.zip?raw=true) · [Vista móvil](TOYP_Panel_Movil.png) · [Código fuente](../../projects/toyp-votacion/)

Panel para 20 perfiles y 10 jurados, con puntuación de 1 a 10, administración y desempates. Los perfiles son provisionales hasta confirmar los 20 postulados. El proyecto requiere un servidor con Python, almacenamiento persistente y HTTPS para uso real. Instrucciones de instalación y generación privada de credenciales dentro del ZIP.
