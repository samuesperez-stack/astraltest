# TOYP — revisión V4

20 segundos, 1080×1920, 60 fps.

[Descargar video](TOYP_Completo_V4.mp4?raw=true) · [Proyecto editable](TOYP_Completo_V4_Proyecto.zip?raw=true)

Títulos del mosaico, jurado, decisión y carrusel centrados también verticalmente. Apertura y desplazamientos del carrusel más largos, con aceleración y frenado suaves. Se retira Inspired y su crédito; esta versión contiene exclusivamente efectos de sonido originales. El cierre conserva fecha y contactos.

Composición `ToypFullV4`, comando `npm run render:v4`. Las composiciones anteriores permanecen en el proyecto con sus assets y licencias, pero su música no forma parte de este MP4.
