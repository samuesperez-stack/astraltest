# TOYP — De +40 a solo 10

Pieza vertical Apple-style aprobada en planificación: mosaico → pliegue → diez categorías anónimas → SOLO 10 → cierre institucional. 18 segundos de video, 1080×1920, 60 fps. Sin voz en off.

- **TOYP_40_A_10.mp4**: video completo.
- **TOYP_Mosaico_Preview.mp4**: fragmento de escaneo, tarjetas y clímax.
- **TOYP_Mosaico_Proyecto.zip**: código Remotion, 41 retratos procesados, música, fuentes con licencias y documentación; npm ci y npm run render.
- **TOYP_Mosaico_Encuadres.jpg**: revisión visual.
- **verification.json**, **SHA256.json**: comprobaciones y hashes.

42 fotos recibidas, 41 distintas: un duplicado eliminado del mosaico. Se corrigió una orientación y se recortó el rostro de una imagen documental para excluir datos personales. Las fotos originales permanecen en el entorno y no están en este ZIP. El mosaico no señala diez ganadores; las tarjetas representan categorías. Etiquetas abreviadas en pantalla y nombres completos en el proyecto.
