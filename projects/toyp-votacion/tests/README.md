# Simulaciones

`python tests/test_api.py` necesita httpx (`pip install -r requirements-dev.txt`). Utiliza exclusivamente una base temporal y verifica autorización, preparación de perfiles, versiones, bloqueo, importación y origen.

Las pruebas de navegador se ejecutan solo con `TOYP_TEST_ONLY=YES` y URL localhost. Requieren Playwright instalado para Node y Chromium disponible en `/usr/bin/chromium`. Son destructivas respecto a la base de prueba: crear una base SQLite nueva en `/tmp`, generar la lista de códigos de prueba con `setup_access.py --output /tmp/toyp-codigos-prueba.txt`, y preparar sus 20 fichas de ejemplo. Nunca dirigirlas a una instalación real. Establecer `TOYP_TEST_CREDENTIALS` con el archivo de prueba y `TOYP_TEST_URL` con la URL local del servidor de prueba. Ejecutar `node tests/juror.cjs` y luego `node tests/round.cjs` sobre esa misma base; `node tests/conflict.cjs` requiere otra base nueva con las 20 fichas preparadas. Se prueban conexión, reconexión, sesión, 20 notas, dos rondas y conflicto entre dispositivos.

Para probar las categorías usa bases separadas y desechables `/tmp/toyp-test-*.sqlite3`, con `TOYP_TEST_ONLY=YES`. Después de crear las cuentas, `python tests/create_categories_fixture.py` prepara las cuatro categorías ficticias. Ejecuta `node tests/categories-ui.cjs` para jurado y `node tests/admin-categories.cjs` en una segunda base nueva para administración; se comprueba que la actualización periódica no borre cambios pendientes.
